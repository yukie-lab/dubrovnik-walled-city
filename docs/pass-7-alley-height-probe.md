# 第7パス(2)— 「北の家並みに 1 層足す」を、決める前に測る

第6パスの終わりに三人の批評家が別々に到達した結論 —
**「空のリボンを実在の 7〜11° に近づけるには、北の家並みに 1 層足す以外に道がない。
それは第3パスの屋根の海と第4パスの視線を動かすので、このパスの権限では決められない」**
に対し、ユーザーの指示は **「まず実測してから決める」**。

**試作を当てて数字を出しただけで、採用はしていない。** 測り終えて `src/plan.js` は戻してある。

## この計測から言えること

批評家の前提のうち**半分は当たっていて、半分は外れていた**。

- 当たり: 1 層足せばリボンは動く(18.1° → 15.8°)。ただし **7〜11° には届かない**。
- 外れ: 「第4パスの視線を動かす」— **A は動かさない**。海も島も山も画素単位で不動。
  視線を動かすのは B(キャップ)だけで、その B はリボンを 0.1° しか改善しない。

7〜11° に入れるには、残る道は**設計幅 2.18 → 1.9m**(画家の案)か **2 層**。
どちらも通行判定と `life` の配置に触れるので、別の判断になる。
