# パス3「屋根」— 採点表と調和の門

対象: 城壁の歩廊から見たテラコッタの継ぎはぎ。**屋根の海が何十もの橙で揺れること。**
ベースライン: **`S5`(第2パス採用版)**。反復 `RA`〜`RE` → **`R3`(採用)**。
定点・時刻・seed は第1・2パスと同一。
**`sea.js` / `light.js` / `sky.js` / `main.js` の後段 / 石の生成器と材質は一行も触っていない。**

## 計器 — `tools/roofstat.mjs`

同じ定点を三回描く。①本番の絵 ②部位の分類マスク ③**屋根 1 軒ごとに固有の色を
配ったマスク**(`instanceColor` に id を焼く)。③があるので「軒ごとの平均色」が取れる。

**「何十もの橙」は軒と軒の差**であって、瓦一枚の差でも列の焼きむらでもない。
- **ΔE群** — 軒ごとの平均色を CIELAB で ΔE 3 に丸めて数えた「区別できる橙」の数
- **軒間σ / 軒内σ** — 家から家への差 / 1 軒の中の差
- **r2/r8/r32/r96** — 屋根画素だけの尺度別局所SD(r2 = 瓦一枚、r96 = 屋根の海のうねり)

## 三人が独立に同じ二つの根に到達した

**(1) 赤い地図に赤い個体色を掛けて、R/G を二乗していた。**
旅人が分解実験で決着をつけた(`v4_srd_t2noon`、屋根画素 159,376):

| 実験 | L\* | h° | R/G |
|---|---|---|---|
| 現状(地図 × 個体色) | 50.3 | **35.9** | **3.31** |
| 個体色を白に(地図だけ) | 72.2 | 50.3 | 1.75 |
| 地図を白に(個体色だけ) | 70.7 | 54.7 | 1.80 |

**片方ずつなら正しいテラコッタ。掛けた瞬間に朱になる。** 同じ絵の中の素焼きの植木鉢が
h 43.9° / L\* 59.9 なのに、同じ素焼きの瓦が h 25.0° / L\* 28.3 だった。
画家は同じことを別の道で測り、**書かれた色相幅 14.5° が画面では 3.9° に潰れ、
青チャンネルがリニア 0.0024(石灰岩の 1/100)まで落ちて夜の穴になる**と示した。

**(2) 瓦の目が二重に引かれていた。**
`vTileUv = uv * instScale / coverM` だが、**斜面は z 方向に D/2 しか張らないのに
uv.y は 0..1 を張る**ので、x は 1 単位 = 2m、y は 1 単位 = 1m の非等方。結果:

| | 実測 | 実物のクパ・カナリツァ |
|---|---|---|
| アルベドの働き幅 | 180mm | 155〜185mm ✔ |
| アルベドの働き長さ(斜面上) | **181mm** | 290〜330mm ✘ |
| シェーダの縦縞 周期 | **370mm** | (アルベドの 2.06 倍) |
| シェーダの段影 周期 | **383mm** | (アルベドの 2.12 倍) |

比が 2.06/2.12 なので位相が約 7m でずれ、**近くでは寝かせたレンガ壁、少し離れると波板**に
なる。城壁から屋根海を見る 72〜149m の帯は、まさに偽の 370mm の縞しか見えない距離帯。

## 何を変えたか — すべて屋根の側

1. **二重の赤をほどく**(`tex.js` の `roofTiles`)。地を `hsl(21,42%,46%)` から
   `hsl(24,15%,70%)` へ、瓦一枚を `lit 46/hue 19/sat 40` から `70/24/15` へ。
   **地図は「形と素地」、色はインスタンス側だけが持つ。**
2. **UV の非等方を直す**(`buildings.js`)。`uv * vec2(instScale.x, instScale.y * 0.5) / coverM`。
   働き長さが 181mm → 318mm(実物 290〜330mm)。
3. **シェーダの縞を実寸へ**。列 `0.36` → `0.15`(= 300mm)、稜 `0.185` → `0.09`(= 180mm)。
   二重の格子が消え、周期が一本になった。
4. **溝瓦と丸瓦の交互**。対称な半正弦(= トタンの波板の断面)をやめ、1 モジュール 180mm を
   丸 76mm + 溝 104mm に割った非対称の断面へ。
5. **窯むらに色相を持たせる**。リニア空間の乗算スカラーは色度を変えない。
   チャンネルごとに違う量を掛けて、明度だけでなく色相も動かす。単位は 1 列ではなく 4〜6 段。
6. **遠景のエイリアスを殺す**。`fract`/`sin` の縞はミップに落ちないので、
   `fwidth(vTileUv)` で振幅を距離に応じて生のテクスチャへ戻す(1 命令)。
7. **パレットを二軸に**(`buildings.js`)。四段が (明度, 彩度) の完全に単調な一本の対角線で、
   **「明るくて鈍い瓦」= 褪せた薔薇色が 586 軒中 0 軒**だった。色相・彩度・明度を独立に。
   構成比も史実へ(1991-92 年の砲撃後に大半が葺き替え → **新瓦が多数派**)。
   色相と明度に同じ `h.seed` を使って完全相関(0.880)していたので、明度は別の種へ。
8. **葺き替えの区画を百枚単位に**。5×3 枚(0.45m 角の付箋)→ 18×12 枚(3.2×1.8m)。
9. **夜と日陰の穴を塞ぐ**。屋根の `envMapIntensity` が 0.40 で、家の本体(0.60)より
   33% 低かった。太陽項がゼロの夜に屋根だけが青い IBL を受け損ね、石が青灰に落ちるなかで
   瓦だけが煉瓦色で残っていた(相対彩度 C/L が正午 0.69 → 夜 1.33 と**倍近く増える**逆転)。
   0.62 へ。棟瓦も同じ。
10. **棟瓦**。`color` と `setColorAt` が二重に掛かって実効アルベドが sRGB(84,17,2) =
    「乾いた血の色」だった。色は個体色だけが持ち、**その家の屋根の抽選に連動**させる
    (棟は同じ窯の瓦を伏せた物で、独立の色ではない)。地図も与える。7 角 → 10 角、
    長さ分割 1 → 5 で瓦一枚ずつの重なり。妻から 0.20m ずつ飛び出していたのを 0.05m に。
11. **屋根が沈む**。一斜面が四角一枚(平面は定義上うねれない)だったのを 8×3 に割り、
    **棟がいちばん下がり、軒と妻の端では 0 になる**式で頂点シェーダから沈める。
    この形なら鼻隠し・軒天・妻の三角の取り合いを一切変えずに屋根だけがうねる。
    棟瓦にも同じ式を掛けた(`aRoofH` を渡して)。**基準法線は斜面ごとに一つのまま** —
    沈みから法線を計算し直すと、真昼の屋根の海に「折り目」を作っている唯一の物
    (南北二斜面の N·L 比 1.50)が崩れる。
12. **妻壁の白い格子をやめる**。火返しが単色 `0xa9a08d`(L\*61 の新品の石灰岩)で、
    **屋根に挟まれた画素の 42〜67% を占め、四つの視点のうち三つで谷のほうが屋根より
    明るかった**(黄金時間では谷 55.1 対 屋根 24.3 = 谷が 2.3 倍明るい)。
    家ごとの煤けた頂点色(L\* 25〜35)に変え、立ち上がりを 0.22 → 0.10m へ。
    **メッシュは 1 枚のままなので draw call は増えない。**

## 意図的に触らなかったもの

- **`sea.js`(保護)/ 光(保護)/ 石の生成器と材質(保護)。**
- **`buildings.js:458` の斜面の基準法線** — 三人のうち二人が「絶対に触るな」と書いた。
- **軒先の面戸**(瓦の小口の帆立貝形)、**煙突の本数と雨押え**、**勾配の 20.6% が 24° 超**、
  **北面の地衣・南面の褪せ・軒際の黒い筋**(方位と水の流れに相関した経年) —
  瓦葺き職人の所見 6・7・8 と画家の所見 6。いずれも `aPart` 属性やワールド法線の
  varying を足せば draw call ゼロで入るが、今回の変更量がすでに大きいので次の機会に回した。

## 下がったもの(報告)

- **屋根が海に対して明るくなった。** 屋根/海 Y比が 0.61 → 0.78(正午)。画家は
  「屋根は一段暗く、一段強い色であるべき」として 0.48 を目標に挙げ、旅人は
  同じ絵の植木鉢を基準に L\* 62〜65 を挙げた。**この二つは両立しない。**
  色相(両者一致、45〜48°)と彩度差(0.041→0.078)を優先し、明度は
  一度下げて 0.82 → 0.78 に留めた。さらに暗くすると旅人の基準点から外れる。
  **どちらを採るかは判断を要するので、明記して残す。**
- **黄金時間の軒間σh° が下がった**(6.8→6.2 / 10.1→6.0)。低い太陽では
  すべての屋根が同じ橙の直射を受けるので色相が揃う。物理としては正しいが、数字は下がっている。
- **三角が 6.9% 増えた**(3.12M → 3.33M)。屋根の分割(8×3)と棟瓦の 10 角 5 分割。
  draw call と fps は不変。
- **`v4_srd_t1am` の ΔE群 が 14 → 13** と 1 だけ減った。ほかの 10 枚は増か不変。
