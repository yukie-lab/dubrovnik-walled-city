# パス4「山と島」— 採点表と調和の門

対象: スルジ山の乾いたマキと剥き出しの石灰岩、ロクルムの松と糸杉、
明るい海を背にした木の輪郭。
ベースライン: **`R3`(第3パス採用版)**。反復 `MA`〜`MI` → **`M2`(採用)**。
定点・時刻・seed は第1〜3パスと同一。
**`sea.js` / `light.js` / `sky.js` / 霧 / 石 / 屋根は一行も触っていない。**

## 計器 — `tools/terrainstat.mjs`

面と輪郭を別の物差しで測る。
- **面**: 尺度別の局所SD を **L\* 単位**で(人の弁別閾はおよそ 1 L\*)。`/空Y比`。CIELAB。
- **輪郭**: `silK` = 輪郭画素 ÷ 面積(**塊は小さく、一本ずつ立つ木は大きい**)、
  `silΔY` = 海や空と接する輪郭を跨ぐ L\* 差。

## 三人が独立に同じ根に到達した(そして三つとも別の層だった)

**(1) 噪声が格子で折り返していた**(画家)。頂点色を駆動する
`n2 = fbm2(x*0.031)` の第1オクターブは波長 **32.3m**、格子は `step = 42m`。
ナイキストの半分以下なので、噪声は頂点ごとの疑似乱数へ折り返され、Gouraud 補間と
ミップで平均されて消える。**書かれていた 34 L\* の意図が 0.8 L\* しか届いていなかった。**

**(2) 相が飽和していた**(旅人)。`rockF` に `smoothstep(120,260,y)*0.65` があり、
y>260m は無条件で rockF ≥ 0.79。可視域の実測で **rockF ≥ 0.9 が 38〜45%**、
頂点アルベドの SD は **3.28 L\***。暗いマキは見える範囲に一度も出ない。

**(3) テクスチャが無地と統計的に区別できなかった**(植物学者)。`scrubTex` を
**同じ線形平均の 4×4 単色に差し替えて実測**したところ、画面の局所SD は
r1 で 0.03 L\*、r64 で 0.01 L\* しか変わらなかった。**弁別閾の 1/30。**

そして**三人ともが**、四つ目を独立に見つけた:

**(4) `macroVariation` が `onBeforeCompile` を連鎖せず代入していた。**
`ground.js` の他の patcher(`patchSkyVis` / `patchWet` / 石段 / 磨石)はすべて
`const prev = …; if (prev) prev(sh, r);` で巻くのに、`macroVariation` だけが上書きする。
`nearMat` の呼び出し順が「三平面を代入 → patchSkyVis → **macroVariation**」だったため、
**三平面投影・マキの粒・天空可視率が丸ごと破棄されていた**。
実コンパイルされた GLSL を捕まえて確認済み(`mapScrub` も `vWPos` も `vSkyV` も無い)。
併発の地雷として、`scrubTex` が `coverM` を返さないので
`` `${(tex.scrub.coverM*0.45).toFixed(2)}` `` は文字列 **`"NaN"`** を生む —
連鎖だけ直すと GLSL が未定義識別子で落ちる。コードが死んでいたので露見しなかった。

## 何を変えたか — すべて山と島の側

1. **噪声を格子が解ける波長へ**(`ground.js`)。`fbm2(x*0.031)`(32m)→ `0.0072`(139m)と
   `0.0032`(313m)。plan.js が既に高さへ刻んでいる**谷筋**を色にも読ませる。
2. **相の駆動を高度から噪声へ**。`rockF` を `0.40 + (n2−0.5)*1.95 + (n−0.5)*1.05 +
   slope*0.45 − gul*0.32` に。可視域で二相がはっきり空間的に分かれる。
3. **四相へ**。マキ / 白い露頭 / その日陰 / **2000 年代の山火事の焼け跡**(別の低周波で切る)。
4. **遠いほど冷たい面の色**。1.5km 先の石灰岩は日陰の微細凹凸と暗いマキが支配するので
   実際に青灰になる。これは霧ではなく「その距離での面の色」。
5. **夜の遮蔽**。遠景メッシュに天空可視率が一度も焼かれていなかった。高さと同じ噪声から
   遮蔽項を作る(形と必ず一致し、コストはゼロ)。**拡散面がその光源である空より
   明るくなることは、アルベド ≤ 1 なので原理的に無い。**
6. **遠景に法線マップ**。`tex.rock` は層理を焼いてあるのに、遠景だけ持っていなかった。
   タイルは 60m → 150m(規則的な縞を避ける)。
7. **`scrubTex` に平均を変えずに分散を入れる**。明度の振れを 38/60/64 から 28/46/76 へ開き、
   alpha を 0.12/0.16/0.14 から 0.34/0.40/0.45 へ。遠景用の大筆を 2 本追加。
   **平均を動かさないのは、第1パスで採点済みの空気遠近に触れないため。**
8. **三平面を二尺度に**(74m と 213m、比 2.88)。一尺度だと 1.2km の山に同じタイルが
   20 回出て斜めのキルトになる。
9. **死んでいたシェーダを復活**(`ground.js`)。`macroVariation` 本体は直さず、
   `nearMat` の**呼ぶ順だけ**を入れ替えて連鎖させた(本体を直すと `stradunMat` の
   効果も復活し、保護対象の石が動く)。`scrubTex` は `coverM: 22` を返すようにした。
10. **葉が幹より暗いという逆転**(`tex.js` / `trees.js`)。`tube()` の頂点は UV を持たず
    「不透明の隅」(純白)を読むので幹は map=1.0、一方、葉は房の平均 0.2623 を掛けられて
    3.8 倍暗くなっていた。房を明るくし、隅に樹皮の縦筋と割れ目を焼き、
    `tube()` に**隅の中を舐める UV** を与えた(1 テクセル固定をやめた)。
11. **樹冠の被覆率 37% → 約 78%**(`trees.js`)。房を 0.155H → 0.200H、枝先の房を 3 に。
    **外周のレースは閉じない**(逆光で空が透ける唯一の仕掛け)。
12. **葉の間接光から空の青を抜く**(`trees.js`)。量を落とすだけでは足りず、
    樹冠そのものの色相が 254°(空 257°)になっていた。残った間接光を
    葉自身の色比 (0.62, 1.00, 0.72) へ染め直す。房を明るくしたぶん逆光透過は 0.42 → 0.20。
13. **糸杉の縦横比 9.1〜13.3 → 6.2〜8.7**。642m で幅 1.0〜2.9 画素では、
    全樹木の 18% を占める糸杉が画面に一本も読めない。
14. **ロクルムの汀の砂色をやめる**。実測 L\* 51.9 の明るい帯が島の全周を回っていた
    (コメント自身が「環礁に見える」と警告していた症状)。L\* 約 37 の岩へ。

## 意図的に触らなかったもの

- **保護ベースライン一式**(海・光・霧・石・屋根)。
- **`macroVariation` 本体**(下記「報告」)。
- **スルジ山に木を植えること**。1.2km で 1m の株は 0.8 画素以下。画家の指摘どおり
  三角の配分が逆(画面 11〜17% の `ground.far` が 16,560 三角、画面 0.4〜1% の
  `surround.pine` が 320,644 三角)。**幾何ではなくアルベドで解く**方針を採った。
- **ロクルムの標高を 30m → 81m にする案**(旅人の所見2)。島の体を厚くする改修は
  `chart.js` の海図・`sea.js` の楕円・歩行網に波及するので、今回の変更量を超える。
- **ケーブルカー**(旅人の所見8)。

## 下がったもの・報告すべきこと

### ① 保護対象に関わる発見 — 判断を仰ぎます

`macroVariation` の連鎖漏れは `nearMat` だけでなく **`stradunMat` にも起きています**。
呼び出し順は 669 行で鏡面の丈のクランプを連鎖代入 → **686 行で `macroVariation` が上書き**。
つまり **第2パス(石)で入れた「比を保った鏡面の丈のクランプ」は一度も動いていません。**
(第2パスでこのクランプを色相保存型に変えたとき、測定値が 11.03% → 11.03% と
まったく動かなかった理由がこれでした。当時は原因不明のまま先へ進んでいます。)

これは**このパスが起こした退行ではなく、ずっとその状態だった**ので、
キャンペーンの規約(「先行要素の再調整で直してはならない」)に従い、
**直さずに報告します**。直せば石の見えが変わり、第2パスの採点表がその分だけ無効になります。

### ② 山と島の側で下がったもの

- **`v6_lovrijenac` の遠景の丘が明るくなった**(山/空 Y比 正午 0.78 → 0.91、夜 0.27 → 0.38)。
  露頭の明度を上げたぶん。中距離の冷却(180〜900m)で 0.96 → 0.91 まで戻したが、
  R3 の 0.78 には届いていない。主役の `v4_srd`(画面 16.9%)が 1.35 → 0.96 と
  大きく改善したのと引き換え。
- **正午のスルジの稜線コントラストが下がった**(silΔY 4.6 → 2.3)。山が空と同じ輝度に
  近づいたぶん、稜線が溶ける。稜線に低木のシルエットを置く案(植物学者・旅人)は
  幾何が増えるので見送った。他の三時刻は上がっている(1.8→2.8 / 6.2→7.0 / 1.7→4.9)。
- **`v3_roofs` の木のシルエット強度がやや下がった**(silΔY 25.3 → 19.9、正午)。
  樹冠が塊になったぶん、輪郭の総延長が減った(silK 0.298 → 0.208)。
  夜と `v5_sea` では逆に上がっている。
- **642m での木の色相は青いまま**(230°)。実測で画素の輝度の約 6 割が大気側になるため。
  葉のアルベドを 1.35 倍に上げたが、それ以上上げると保護済みの関係
  「暗い糸杉 対 明るい水」(植生/海 Y比 0.24〜0.49)を壊す。**霧は保護済みなので、
  この二つは山と島の側だけでは両立しない。** 近い木(130m)は 148° の緑で正しく出る。
