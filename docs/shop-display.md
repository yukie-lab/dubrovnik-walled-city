# 大通り沿いの商品棚とカフェリンクの整理

2026-10-03。ユーザーの依頼により、画面左上の「カフェ前へ」リンクを削除し、
ストラドゥン沿いのショップの商品棚を更新した。

## 表示と操作

- カフェの画面リンク、CSS、クリック処理を削除。既存の C キーと徒歩の入退店は維持。
- 97か所の棚表示を、色付きの長方形から瓶・瓶詰め・陶器・紙箱に変更。
- 店ごとに食料品、ワイン、陶器の3系統の品揃えを固定 seed で割り当てる。
- オイル瓶の肩と首、ワインの口部、瓶詰めの蓋、陶器の丸みと器の内側を表現。
- 紙ラベル8種、釉薬の模様、ガラスのハイライト、木の棚板と小さな札を追加。
- 商品の寸法と奥行きに小さな個体差を設け、部分的な売り切れの空きも残す。

## 実装

`src/shop-display.js` に店舗表示を切り出した。開口の描画面から視線を延ばし、
有限の箱・円錐台・楕円体との交差を求めて棚と商品を描く。
斜めから見ると棚板や商品側面が見え、商品同士と棚の前後関係も視点に従う。
器には外側と内側の曲面があり、上から覗くと中が見える。

既存の店舗用 InstancedMesh を使い、描画呼び出しは増やさない。
店ごとの seed と品揃えは専用のインスタンス属性。商品ラベルはコード生成した
キャンバスアトラスを共有する。開口上部も石アーチの内周に合わせて切り抜く。
ガラスは色付きの拡散・ハイライトで近似し、店内照明の営業時間は既存の時計に従う。
ショーウィンドウ内の描画を更新したもので、店舗の入退店範囲・建物の衝突は変更しない。

87材質の検査でプログラム衝突・欠落0。正面と斜めの瓶・陶器・ラベル、夜間の減光を目視確認。
左上のリンクが DOM に存在しないことと、C キーでカフェ前へ移動できることも確認。

カフェの昼・夕方・夜×3視点の9条件も安定し、実キー入力で入退店できる。
通常プレイの夜間露出順応100サンプルは有限値を保ち、屋外へ戻ると屋内測光が解除される。
