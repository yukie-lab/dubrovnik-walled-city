# パス1「光の模型」— 採点表と調和の門

対象: 太陽・空・影・環境バウンス・大気の霞・露出とトーンマッピング、四つの時刻すべて。
反復: `L0`(ベースライン)→ `L1a` → `L1b` → `L1` → **`L2`(採用)**。
定点は `tools/campaign.txt`(8 視点 × 4 時刻)。seed・anim・画角は全反復で同一。

## 計器を先に直した

三人の批評家が独立に同じことを指摘した — **`tools/lightprobe.mjs` が IBL を数えていなかった。**
半球光しか積分していなかったので、報告されていた「日向:日陰 7.31:1」は実在しない数字だった。
IBL の放射照度(env 球の式をフィボナッチ球 4096 方向で数値積分)を加えると、
黄金時間の立面は **2.73:1** だった。**直す前に計器を直す。**

同じく、撮影時に表題の幕(2.2 秒のトランジション)が消えかけで焼き込まれており、
消え具合が読み込み時間で変わっていた。同じ定点の 2 枚が比較できない状態だったので、
撮影では要素ごと外すようにした。ベースラインはその後に撮り直している。

## 調和の門

全景の定点 32 枚を撮り直し、要素別分類マスク(`tools/harmony.mjs`)で関係を測った。

| 暖かい石 対 空 | 正午 不変(0.95→1.02 ほか ±8% 以内)。黄金は石が沈む(下記「下がったもの」) |

## 何を変えたか — すべて物理

1. **天空の高度追随を空の色そのものに一度だけ掛けた**(`sky.js`)。
   これまで `pow(sin el, 0.45)` は半球光にだけ掛かり、IBL と天蓋は満額だった。
   黄金時間には IBL が半球光の 2.66 倍になり、**影を落とさない第二の太陽**として
   立面の日向:日陰を 2.73:1 に潰していた。水平線の焼けだけは対象外(床 0.42)—
   日没の水平線は正午の水平線を下回りこそすれ、上回らない。
2. **IBL の空を天蓋と同じ分布・同じ方位依存にした**(`light.js`)。
   仰角の重み `pow(d.y,0.6)` → `pow(1-d.y,3.2)`(天蓋と同式)、
   水平線を `mix(horizonFar, horizon, smoothstep(-0.4,0.9,dot(d,sunDir)))` に。
   **見える空と照らす空が同じ物になった。** これで日没に「太陽を向いた壁は橙、
   背を向けた壁は青」が成立する。半球光は方位を持てないので環の平均を担う。
3. **地面バウンスを実際の地面放射照度から導いた**(`sky.js` の `hemiGround`)。
   `dusk`/`night` のランプでは、水平直射が正午の 1/55 になる黄金時間でも 0.55 倍
   にしか落ちず、昼の全時刻で半球光の下半分が上半分より明るかった(1.12〜1.89 倍)。
   正午の値を固定点にしたので、正午の絵は動かない。
4. **太陽の色を波長別 Beer–Lambert に置き換えた**(`sky.js`)。
   二段の HSL 補間は `warm` が am 6.85 で頭打ちになり、到達点自体が 3900K だった。
   Rayleigh + 海洋性エアロゾル + オゾンの分光積分に 1% で一致する二定数
   (τ_G−τ_R = 0.058 / τ_B−τ_R = 0.215)。**色度だけを持たせ、輝度は
   `sunIntensity` に任せた** — 以前は色の暗さが二つ目の減衰として効いていた。
5. **`dusk` の二役を分けた**(`sky.js`)。水平線の焼けは大気路程 `warm` で、
   天頂の菫は日没後に始まる `smoothstep(2,-8,el)` で駆動する。
6. **霧を方位依存にした**(`light.js` の `patchDirectionalFog`)。
   `<fog_fragment>` を差し替え、視線方向と太陽方向から太陽側/反対側を混ぜる。
   天蓋と同じ式・同じ引数なので、水平線で必ず連続する。
   昼の霧色に天頂を 28% 混ぜた(遠景が載る仰角 +6° の実際の空の組成)。
   これで「1.5km 先の山がその上の空より 38% 明るい」逆転が消えた。
7. **夕方に霧の密度を倍にするのをやめた**(`light.js`)。夕方に増えるのは
   太陽光が通る**斜めの道のり**(= am、`sunCol`/`sunIntensity` が既に持っている)で、
   観測者から山までの水平方向の視程ではない。0.00125 → 0.00072。
8. **露出を高度の二本の曲線から、実測の水平面全天照度に変えた**(`light.js`)。
   `noonK`(高度で下げる)と `lowSunK`(高度で上げる)の積は el 20.6° で
   両方が持ち上げ端にあり、逆光のストラドゥンを正午より 21% 明るく撮っていた。
   `0.88 × (GHI_noon / GHI)^0.155` の一本に。順応は部分的(夜が昼にならないよう)。
9. **影の接地**(`light.js`)。低い太陽で影ボリュームを**広げて**いたのを絞る向きに
   変え、バイアスを「1 テクセルぶん動いたときの深度差」= `texel·cos(el)` から導いた。
   固定値 `0.156·sin(el)` は sin に床 0.28 があり、el 16.3° 以下で補正が止まって
   後退量が 1/sin(el) で発散していた。
10. **太陽の暈と後段**。暈の裾 `pow(sd,40)`(半値角 10.6°)→ `pow(sd,150)`(5.4°)、
    ブルーム半径を昼だけ 0.35 → 0.18、グレードのニーの入口 0.82 → 0.90
    (0.82 では局所傾き 1.58 = 圧縮ではなく伸長だった)。
11. **夜**。IBL を夜に上げるのをやめ(0.74 → 0.66)、月を 2.2 → 1.5 に、
    中間視(プルキンエ)の彩度低下 `satW *= 1 - 0.30·uNight` を足した。
    月光の赤瓦が正午より赤いという逆転が消えた。

## 意図的に触らなかったもの

- **`src/sea.js`** — 保護ベースライン。一行も変えていない。海の見えが動いたのは
  すべて光の側(空の輝度・霧・トーンマップ)からの結果。
- **半球光と IBL の二重計上そのもの。** 「半球光を消して IBL 一本に」は二人の
  批評家が提案したが、自分で測ると路地の正午では形(標準偏差)が増える一方、
  城壁の黄金時間では減った(変動係数 0.538 → 0.455)。証拠が割れたので、
  症状(高度追随の欠落)だけを直し、構造の変更は見送った。
- **石・屋根・山・木の材質** — 後のパスの領分。
- **霧の基準密度 0.00062** — 下げると海の距離減衰(`sea.update` に渡している)が
  動く。物理的にはもっと薄くてよい(視程 25km なら 0.00039)が、保護された海に
  触るので、夕方の非物理な増分だけを削った。

## 下がったもの(報告)

- **黄金時間の絵が暗くなった。** 8 枚平均で 中央値 0.244 → 0.124、暗部<0.02 が
  0.7% → 8.7%。石/空 Y比 も 0.23→0.13(路地)、0.30→0.19(ルジャ)。
  19:18 の街の底が実際に影であることの帰結で、絵としては読める(路地・スルジ・
  ロヴリイェナツを実見して確認)が、**数字の上では確かに沈んでいる**。
  もっと明るくしたいなら露出の冪(現在 0.155)を上げるのが一箇所の変更で済む。
- **朝の絵も暗くなった**(中央値 0.324 → 0.222、暗部 0.9% → 5.2%)。朝の空が
  正午より明るいという逆転を直した帰結。
- **夜の海の彩度が落ちた**(v5 の B/R 2.84 → 2.07、彩度 0.665 → 0.535)。
  中間視の彩度低下による。海は保護対象なので明記する — 意図した変更だが、
  「夜の海はもっと青くあるべき」なら、その項(`main.js` の `satW *= 1-0.30·uNight`)
  を弱めるのが一箇所の変更で済む。
- **水平線での海と空の分離は解けていない。** 海/空 Y比 は依然 0.97〜1.12。
  ベースラインからの退行ではなく元からの弱点で、原因は霧色と天蓋が同じ二色から
  作られていること。**「空」のパス(第5)の主題(水平線へ向かって濃くなる霞)と
  同じ場所なので、そこで扱うのが筋**と判断して持ち越す。
- **正午のスルジ山は依然として空より明るい**(1.30 → 1.35)。北向きの構図では
  反太陽側の空が最も暗く、日の当たる南斜面が明るいのは実在でもそうなので、
  逆転とは判定していない。山の平板さ自体は第4パスの領分。
