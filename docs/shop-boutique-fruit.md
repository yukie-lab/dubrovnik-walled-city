# 女性向け靴・ハンドバッグ店と果物屋

2026-10-04。ユーザーの依頼により、既存の8業種に2業種を追加した。

- バッグの看板: ヒール付きパンプスとハンドバッグ。黒・ボルドー・キャメル・
  ベージュの革を使い、バッグに前後の持ち手、フラップ、留め金、縫い目を表現。
  パンプスは細いヒール、傾斜した靴底、内側が空洞の履き口を持つ。
- 果物の看板: リンゴ・オレンジ・洋梨・ブドウ・レモンを浅い木箱に並べる。
  リンゴのくぼみ、洋梨の首、ブドウの粒、レモンの両端、皮の色と粒状感を描き分ける。
  木箱は底・側板・前後の横桟を持ち、3段の棚に4箱ずつ置く。

97か所の店舗表示のうち、靴・バッグ店8か所、果物屋5か所を固定の座標規則で
割り当てる。その他の84か所の業種は維持。看板と棚は共通の業種定義を使う。
カフェ付近の看板付き店舗は、靴・バッグ店が x=-45.718、果物屋が x=-95.187。
どちらもストラドゥン北側。

看板アトラスは4列×3行に拡張。従来の絵のセル解像度・余白は維持し、
新しい看板の乱数を分離して日よけなどの既存テクスチャに影響させない。
新商品の形状・材質は `src/shop-boutique-fruit.js` にまとめ、既存の共有描画面に統合。
店舗アーチ、扉、衝突範囲、地理、営業時間の制御は従来どおり。
