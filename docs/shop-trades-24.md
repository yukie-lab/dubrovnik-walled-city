6業種(ネクタイ店・宝飾店・蝋燭屋・ジェラート屋・楽器店・船具店)を加えて24業種にし、
97軒すべての業種割り当てを通り全体で組み直した。建物・看板・店舗の位置と総数は変えていない。

## 割り当ての組み直し

これまでは業種を足すたびに、既存の店の一部を座標のハッシュで新業種へ回していた。
そのため後から足した業種ほど軒数が偏り、同じ業種の店が隣り合うこともあった。

`assignShopTrades`(`src/shop-catalog.js`)は通り全体を一度に配る。

- 通りに沿って並べた97軒を4つの区間に分け、各区間に24業種を1軒ずつ置く(余りの1軒はお土産屋)。
- 区間内の入れ替えだけを使う決定的な焼きなまし(乱数の種は固定、60,000手、約0.1秒)で、
  吊り看板の数と通りの南北を業種ごとにそろえる。
- 同業の店が区間長の6割より近いほど罰する。遠ければ遠いほど良いとはしない
  (そうすると、どの区間も同じ順番の繰り返しになる)。
- 隣の店や向かいの店が、同業や見た目の似た業種(食器と花瓶、靴屋とバッグ店、パン屋と粉屋など)にならないようにする。
- 同じ業種の組み合わせが隣どうしになるのは1回までとする。
- 結果は店の位置だけで決まる。看板と商品棚はこの結果だけを読むので、常に一致する。

| | 13業種(コミット済み) | 18業種(未コミット) | 24業種(今回) |
| --- | --- | --- | --- |
| 業種ごとの軒数 | 5〜10 | 1〜8 | 4(お土産屋のみ5) |
| 業種ごとの吊り看板 | 2〜6枚 | 1〜5枚 | 2〜3枚 |
| 同業の店どうしの最短距離 | 3.1 m | 3.1 m | 26.3 m(業種平均 41.7 m) |
| 同業の店が隣り合う箇所 | 11 | 9 | 0 |

通りの南側(海側)に50軒、北側に47軒ある。どの業種も南北に2軒ずつで、
仕立て屋(南3・北1)とお土産屋(南3・北2)だけが南側に1軒多い。
隣・向かいの165組に同業の組はない。同じ業種の組み合わせが2回現れるのは、酒屋と花瓶の店の1組だけ。

## 看板の縦横比(既存の不具合)

看板の絵は縦に約3.6倍つぶれていた。正方形の絵を128×256 pxのセルに描き、
そのセルを横長の板面(0.52 × 0.30 m)に貼っていたためである。
セルの縦横比を板面に合わせた(`SHOP_SIGN_ATLAS.cellAspect`、アトラスは4列×6行、幅1024 px)。
腕金と板の側面は、各セルの金の縁より外側の地色を参照する。この修正は24業種すべての看板に効く。

## 描画負荷

業種を増やす途中で、棚の描画が既存の店も含めて約25%重くなっていた。原因は商品そのものではなかった。
どの画素でも、棚の28区画すべてについて乱数と外接箱を計算していたことが原因だった。
現在は、光線が通る段の帯と列だけを調べる。
帯は商品の拡大率(1.05倍未満)と位置の揺らぎ(±6 mm / ±42.5 mm)を含めて取ってある。
絞り込みを外した同じ版と画素で比べた(24業種×4視点、96枚)。51枚は完全に一致し、残りの差もほとんどが1階調だった。
9階調以上違う画素は1枚あたり最大4個で、どれも輪郭上の孤立した画素だった。商品の欠けはない。

店の窓が画面を埋める視点で棚のメッシュだけを描画し(1600×1000、dpr 1)、ヘッドレスの Chrome(Metal)で計測した。
同じブラウザで版を交互に計測し、温度による変動を打ち消した。

| | コミット済み(13業種) | 今回(24業種) |
| --- | --- | --- |
| 既存13業種の窓 | 10.7〜13.8 ms | 7.3〜8.9 ms(×0.65) |
| 追加11業種の窓 | — | 7.5〜8.5 ms |

## 検証

```sh
node tools/rendercheck.mjs shop-trades-24 --shop-display --program-audit --program-strict
node tools/refinement-protect.mjs
git diff --check
```

24業種の正面・左右(72条件)、18業種の夕方・夜(36条件)、南側の店舗(1条件)の計109条件を撮影する。
全看板と商品業種を照合し、視点移動後の GPU インスタンス属性も検査する。
撮影ツールは、業種ごとの軒数と吊り看板の数の差が1以内であることも検査する。

2026-10-17 の結果:

- 109条件すべてで描画が安定し、看板と商品の食い違い、GPU のエラー、ページのエラーはいずれも0。
- 描画呼び出しは133〜157(上限200)。シェーダーのプログラムは104で、直前のコミットの記録
  ([入口の検証記録](building-entry-check.json))と同数。衝突・欠落・GL エラーはない。
- 店舗97軒、吊り看板60枚。業種ごとの軒数と看板の数は上の表のとおり。
- `refinement-protect`: 保護対象の4ソースと665棟の記録は変わっていない。
