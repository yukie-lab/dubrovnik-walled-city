`src/shop-catalog.js` が看板と商品棚の共通の業種を決定する。
看板アトラスは CanvasTexture の上下反転を考慮して絵と UV の行を対応させる。
2026-10-17 以降は、店の位置だけから通り全体の割り当てを一度に決める(`assignShopTrades`)。
看板がない店舗も同じ割り当てに含まれる。

`src/shop-trade-products.js` に有限の立体形状と材質の表現を追加。
鍵とハサミの持ち手は内壁のある輪で、穴越しに背景が見える。
商品幅に応じて棚の列数を4・5・7列に変え、魚屋は3段のトレーにする。
既存の共有描画面を使い、商品数による描画呼び出しは増やさない。
紙ラベルは薬草店・理髪用品向け16枚に、本用の6枚を追加した。

## 2026-10-03の8業種版の検証

```sh
node tools/rendercheck.mjs shop-trades-final --shop-display --program-audit --program-strict
node tools/rendercheck.mjs shop-trades-tailor --shop-display --shop-trade tailor --program-audit --program-strict
node tools/refinement-protect.mjs
git diff --check
```

8業種の正面・左右の斜め視点、仕立て屋と魚屋の夕方・夜、南側の店舗を撮影する。
全看板の店舗座標と商品業種を照合し、視点移動後にも描画用インスタンスの
看板 UV と商品属性の一致を検査する。

97か所の内訳は、パン14・鍵15・仕立て9・魚14・酒9・薬草14・靴12・理髪用品10。
実際に掲げられた看板60枚すべてが商品の業種と一致する。
最終版の29条件は静止画が安定し、描画140〜153回、GPU エラー0。
87材質の検査もプログラム衝突・欠落0。C キーとリンク削除の状態も維持。
保護検査は4ソース、665棟の配置、城壁・街路・経路・プリセットの保持を確認。

ハサミの刃と支点の最終調整後、仕立て屋の5条件を再撮影して確認した。
結果は [検証記録](shop-trades-check.json) に保存。画像は
`shots/rendercheck/shop-trades-final-*` と `shop-trades-tailor-*` に保存する。
