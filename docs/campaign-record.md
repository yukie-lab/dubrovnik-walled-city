# 逐次精錬キャンペーン — 全記録

海が完成したあと、残りの要素を**一度に一つずつ**、決められた順序で磨いた六つのパス。
各パスは同じ手続きを使った: 動かさない定点、役割の違う三人の批評家、ベースラインに
対する採点表、保護された性質を一つでも下げた反復は不採用、**化粧ではなく物理の変更**、
そして「これ以上の改善は見つからない」で終わってよいという終了条件。

## 変わらなかったもの

- **定点** — `tools/campaign.txt` の 8 視点 × 4 時刻。**キャンペーン全体で一度も変えていない。**
  どのパスのどの反復同士も比較できる。パス固有の診断視点は別ファイルから読む
  (`harmony.mjs --views`)。
- **seed** 19790807、`anim` 40(撮影時固定)、画角。
- **時刻** — `t1am` 7.90(高度 20.6°)/ `t2noon` 12.87(61.2°)/ `t3gold` 19.30(4.7°)/
  `t4dusk` 21.20(−14.3°)。
- **海** — 保護ベースライン。六つのパスを通して一画素も動かしていない
  (第6パス終了時の海クラスの Y の最大変化 1.00%)。
- **批評家の三役** — 一人目だけパスごとに専門を替える(照明監督 → 石工と建築写真家 →
  屋根 → 植物学者 → 地中海の気象学者 → ダルマチアの建築史家)。
  **画家と、この城壁に立ったことのある旅人は最後まで同じ。**

## 六つのパス

### 1. 光の模型 — `ae11c1e`

**根本原因**: 空の高度による減衰が `hemiSky` にしか掛かっておらず、**IBL が影を落とさない
二つ目の太陽として全強度で残っていた**。

黄金時間の立面 日向:日陰 **2.73:1 → 8.00:1**。山/空 0.87 → 0.51。糸杉/水 0.70 → 0.33。
黄金時間の画の彩度 0.250 → 0.348。太陽色は分光(Beer–Lambert + Rayleigh + エアロゾル +
オゾン)から導き直し、リニア B/R が am 10.93 で 0.496 → **0.118**(分光の真値 0.119)。
正午はほぼ不動。描画呼び出し 186 で不変。

### 2. 石 — `5f49c37`

**根本原因**: **目地が石より明るかった**(4 つの生成器のうち 3 つ)。低周波の二色目は
石テクスチャ自身の `.g`(平均 0.465)を変調源にしていたので ±16% のつもりが ±1.7%。
床は画面で最もテクセルの粗い面で、目地が 2px しかなかった。

石段の面の情報 0.084 → **0.275**。磨石の headroom 0.71 → **1.09**。
海側城壁の目地の歪度が四時刻すべてで負(= 明るい面を細い暗い線が割る)。
無彩の白 7.44% → 6.89%。

### 3. 屋根 — `fbb6df1`

**根本原因**: **赤の二重掛け**(`map` × `instanceColor` が R/G を二乗し、色相が 50° では
なく 35.9° になっていた)と、**瓦の目の二重描き**(UV の異方性 2 倍 × シェーダ定数が
アルベドの 2.06/2.12 倍)。

平均色相 29.6°/35.9° → **45.8°/46.8°**。ΔE 群(軒ごとに区別できる橙の数)は 11 行中
6 行で増え、減った行はゼロ。屋根/海の彩度差 0.041 → 0.078。

### 4. 山と島 — `c3aa3b7`

**根本原因**: 一つの症状に三つの原因 — **折り返した噪声**(波長 32.3m を格子間隔 42m で
標本化)、**飽和した `rockF`**、そして**統計的に無地の灰と同一のテクスチャ**。
加えて `macroVariation` が `onBeforeCompile` を**連鎖せず上書き**していた。

スルジ /空Y比 正午 1.41 → **0.96**、夜 1.38 → **0.60**。局所SD +30〜90%。
木の `silK` 0.298 → 0.208 / 0.496 → 0.382。夜の島 L\* 26.6 → 19.9。
「暗い糸杉 対 明るい水」の夜の符号反転(1.45)を 0.88 に戻した。

### 5. 空 — `ae96c09`

**根本原因**: 空に**絵具が一回しか置かれていなかった**。縦のグラデーションを引いた残差
(= 塗り)の中央値 1.93 L\*、うち 3 行は**弁別閾 1 L\* 未満**、つまり定義上ただの
グラデーション。雲は太陽の方向を知らず(陰影がアトラスの縦座標だけの関数)、
暗い側が空より明るく(夜は 4.6 倍)、四時刻とも画素単位で同じ配置だった。
太陽の暈は直径 27°(実在の光冠は 2〜3°)。

塗りの中央値 1.93 → **2.52**、**弁別閾未満の行 3 → 0**。
07:54 の空 B/R 1.267 → 1.462、彩度 0.224 → 0.316。
雲被覆は 07:54 7.4% → 1.2% / 12:52 7.8% → 13.0% / 19:18 17.8% → 10.7% / 21:12 7.9% → 2.1%。

### 6. 体験としての路地 — `c0f8308`

**根本原因**: 家の列を左詰めで詰めるので、**余りは街区の構造上、必ず次の路地の西側に
落ちる**。そこが未建築のまま残り、庭塀の補完が厚 0.5m・高さ最大 10.83m の板で塞ぐ。
`garden` は開口・巾木・縦樋・軒・屋根をすべて失うので、**路地の立面 278m が
「目の無い板」**になっていた。

厚 0.9m 未満の板 40 枚 278m → **1 枚 12m**。実測幅 2.85 → 2.55m、h:w 3.59 → **4.32**。
戸口の敷居 − 足元の地面 p25/中央/p75 = −0.132/+0.251/+0.425 → **0/0/0**。
夜の路地の潰れ(L\*<5)**40.8% → 5.5%**、足元 L\* 2.7 → 20.4。

## このキャンペーンが繰り返し教えたこと

**1. 物を直す前に計器を直せ。** 六つのパスのうち三つで、最初に見つかったのは計器の嘘だった。

- 第1パス: `lightprobe` が IBL を数えておらず、報告された「日向:日陰 7.31:1」は虚構。
  真値は 2.73:1。三人の批評家が独立に指摘した。
- 第3パス: `instanceColor` は `material.vertexColors` に関係なく材質色に掛かるので、
  分類マスクで屋根が画面の 7.8% ではなく 0.2% と出た。
- 第6パス: 私が**四つ**続けて測り間違えた(洗濯物の高さを別の場所の床と比べた、
  路地の代表点が交差点に立っていた、明暗を画面中央値で測った、リボンの角度の式が
  床から測っていた)。三人の批評家が全部捕まえた。

**2. 視野より周期の長い変調は、定数である。** 二度出た。

- 第5パス: 空の筆の支配周期 13° に対し、路地と広場の空の帯は視野 12〜18°。
  その成分はまるごと直流になって消え、残差 0.757 L\*(弁別閾未満)。
- 第6パス: 壁の二色目の周期 68m と 21m に対し、腕の届く壁が張るのは 3m。同じ故障。

**3. HDR で加算した項は絶対量なので、信号が小さいところで爆発する。**
空の加算のむら ±0.022 は、天頂の輝度が 0.090(正午)→ 0.0007(薄暮)と 130 倍動くあいだに
**±12% → ±950%** に化けた。夜空一面の灰色の斑はこれ。比例(乗算)に変えれば消える。

**4. 圧縮的なトーンカーブに対称な揺らぎを通すと、平均が下がる。**
空に塗りを足したぶん、空クラスの平均輝度が 2%・平均彩度が 8% 落ち、水平線で海と空の
色相差が痩せた。持ち上げた量に比例する色度の外挿で相殺した。

**5. 傾いた面を 1 つのスカラーで代表してはいけない。**
路地は勾配 25% で登るのに、面の高さは中点 1 点で決めていた。巾木は石一枚ごとに
地面を測り直していたのに、扉だけがそれをせず、四分の一が舗装に埋まり四分の一が浮いた。

**6. `onBeforeCompile` は必ず連鎖する。**
第4パスで `macroVariation` が上書きしていることを見つけた。副作用として、第2パスで
足した `stradunMat` の鏡面クランプは**一度も実行されていなかった**。

**7. 変更が本当に効いているかを測れ。**
第6パスで `varying` を二重に宣言して GLSL のコンパイルを壊し、マテリアルが代替に
落ちて石が街じゅうで 23〜35% 暗くなった。**門の値を二度変えてもビット単位で同じ結果が
出た**ことで気づいた。

**8. 局所の指標は、何を測っているかを疑え。**
局所SD 8px は「壁に物があるか」を測れない — 縦樋が 6 本写っている画(0.70)と無地の板
(0.58)がほとんど同じ値になる。動くのは日向の面積であって物の数ではない。
旅人の指摘で、壁だけの局所SD と輪郭の割合に替えた。

## 未決の判断 — 第7パスで両方とも解けた(`docs/pass-7-*.md`)

**1. 路地の狭さ。** ユーザーの指示「まず実測してから決める」で試作を測った結果、
批評家の前提は**半分外れていた**。北の第2帯を 1 層上げる(A)と空のリボンは
18.1° → **15.8°**、そして**ミンチェタからの海は 2.9% のまま一画素も減らない**。
視線を動かすのは視線キャップ(B)だけで、その B はリボンを 0.1° しか改善せず、
海を 2.9% → 2.3% 削る。**A を採用、B は不採用。** 実在の 7〜11° には届いていない
(残る道は設計幅 2.18 → 1.9m か 2 層。どちらも通行判定と `life` に触る)。

**2. `macroVariation` の連鎖。** 直した。第2パスで書いた鏡面クランプは
六つのパスのあいだ一度も GPU に届いていなかった。無彩の白 5.19% → 4.31%、
画の p99 1.000 → 0.966(純白の貼り付きが消えた)、磨石の局所SD r1 +59%。

## 積み残し(パスごとの記録に詳細)

- **屋根**: 軒の口を塞ぐ瓦、煙突の数と水切り、勾配 24° を超える 20.6% の屋根、
  方位と相関した風化。
- **山と島**: スルジの稜線の植生、ロクルムの標高、ケーブルカー。
- **空**: 仰角の基底 `pow(1-h, 3.2)`(仰角 40°→84° で 0.3 L\* = 空の上半分が一枚の
  色見本)。`fogMix` の前提と定点が仰角 0〜30° しか見ないことから見送った。
  旅人の三段の重み(半球平均を −0.035% で保存)を控えとして記録済み。天の川。
- **路地**: 手の届く高さの物(郵便受け・番地札・水道元栓・腕木・持ち送り・猫の餌皿)。
  段の履歴(摩耗が 122 段すべてで画素単位に同一)。`house.plinth|steps` の
  相互貫入 1884 件。鉢を窓台と腕木にも。
- **計器**: 「日陰へ入る瞬間」の**過渡**を撮る手段。`main.js:530` の
  `lighting.state.snap = SHOT` により τ が 0.0001 になるので、**このキャンペーンの
  1 枚も順応の途中を写していない**。`glare` は全撮影で恒等的に 0。
