# 本屋・お土産屋・チーズ屋

2026-10-04。ユーザーの依頼で3業種を追加し、看板に対応する品揃えを計13業種にした。

| 店 | 看板 | 商品の表現 |
| --- | --- | --- |
| 本屋 | 開いた本 | 青・緑・赤茶の表紙、背の帯と書名、紙の束。立てた本と平積みの本を混在させる |
| お土産屋 | 人形 | 顔・髪・袖・エプロンを分けた彩色人形、赤い屋根と窓のある小さな家、2枚の帆を張った船 |
| チーズ屋 | 穴のあるチーズ | 木の板に載せた丸いチーズ、切り口にくぼみのあるくさび形、小型チーズの積み重ね |

前回追加した靴・バッグ店と果物屋は維持し、その他の店舗の一部を固定の座標規則で
新3業種に割り当てる。建物や看板の位置、店舗の総数は変更しない。
看板アトラスは4列×4行へ拡張し、既存の絵の解像度と乱数列を保持。
ラベルに架空の本の書名6種類を追加した。

`src/shop-books-souvenirs-cheese.js` に新商品の形状と材質をまとめる。
本の表紙・ページ、置物の各部、チーズの皮と切り口はそれぞれ有限の立体で描画する。
チーズのくぼみは切り口をくり抜いて内向きの曲面を描き、斜めからも奥行きが見える。
家の屋根と船の帆は厚みのある三角柱。既存の共有描画面に組み込み、描画呼び出しは増やさない。
