# ドゥブロヴニク — The Walled City(v2)

実在の地理で歩ける、手続き生成のドゥブロヴニク旧市街。
外部アセットなし(テクスチャ=キャンバス生成、音=WebAudio 合成、モデル=コード)。

## 起動

```sh
cd dubrovnik-walled-city
node tools/serve.mjs 8765
# → http://localhost:8765
# python3 -m http.server は Cache-Control を送らないので、ブラウザが
# src/*.js を握ったままになる(index.html に ?v= を付けてもモジュールは
# 別 URL なので切れない)。直したのに直っていないように見える事故が
# 実際に起きた。tools/serve.mjs は no-store で配る。
```

Three.js は `node_modules/three`(0.185.1 固定)を importmap で参照。ビルド不要。

## おまかせで歩く(自動ウォーク)

タイトル画面の「おまかせで歩く」から4ルート。移動キーを押せばいつでも手動に戻れる。

1. **朝のストラドゥンと路地** — 大通り→階段路地→プリイェコ→鐘楼前
2. **ミンチェタ登頂(黄金の時間)** — ペリネ通り→壁の中の階段室→歩廊→塔頂テラス
3. **城壁一周(大めぐり)** — ピレの大階段から全周(約15分・途中で日が暮れる)
4. **旧港と防波堤(夕暮れ)** — ポンテ門→岸壁→ポルポレラ突端から城を見る

ルート定義は `plan.js` の `makeRoutes` にあり、`tools/walktest.mjs` が
**同じ定義を衝突判定込みで自動歩行**して通行可能性を検証する。

## 操作

| 入力 | 働き |
|---|---|
| W A S D / マウス | 歩く / 見る(クリックでポインタロック) |
| ← → または Q・E | 向きを変える(マウスなしでも歩ける) |
| Shift | 少し速く(それでも散歩) |
| T・G / 右上の弧をドラッグ | 時刻を動かす(世界全体が照らし直される) |
| 1〜4 | しるべの場所(ピレの朝 / 真昼の路地 / ミンチェタの黄金 / 日没の胸壁) |
| M | 手描き地図(慈悲として。迷うのが本体) |
| P | 時の流れを止める / F3 計器 / Esc メニュー |

## 検証(実ピクセル)

```sh
node tools/shot.mjs ミンチェタ:-99:-88.4:-2.36:-0.14:19.7
# shots/ミンチェタ.png + draw calls / tris / fps + 「視線先 ○m」が出る
# カメラが家の中や壁の直前にあると ★屋内 / ★壁に近すぎ と警告する
#   — 屋内から撮ると背面カリングで壁が消え、向こう側の窓枠だけが
#     宙に浮いて見える。これが「バグ」の最も多い誤検出源。
# extra に &fov= / &gy=(地面の高さを指定) / &anim=(アニメの時刻) を渡せる

node tools/shot.mjs $(grep -v '^#' tools/shots.txt | tr '\n' ' ')   # 批評用の定点 18枚
```

定点を新しく作るときは `aim.mjs` が探してくれる。対象の座標と距離の範囲を
渡すと、街路・広場の上で「屋内でなく・視線が通る」点から spec 行を出す。

```sh
node tools/aim.mjs 鐘楼 147 -8 24  20 40  13.4 52
```

画の客観計測は `imgstat.mjs`。リニア輝度の中央値・p1・p99、暗部/明部の割合、
彩度、空と影の B/R 比を出す。**「影が青いか」「白が生まれているか」は目では
測れない** — 数字で見る。

```sh
node tools/imgstat.mjs shots/s0*.png shots/s1*.png
```

`_pick.mjs` は画面座標からレイを飛ばして「そこに何があるか」を返す。
描画の破綻を疑ったら、まずこれで対象を特定してから直す。

```sh
node tools/_pick.mjs "http://localhost:8765/index.html?shot=1&x=..." 830 300
```

## 検証(描かれた三角形を真実として)

`walktest.mjs` と `piercetest.mjs` は **plan.js のモデルを plan.js のモデルで**
測る。モデルが自己整合なら、見た目が壊れていても ALL CLEAN になる。
壁抜け・浮き・海上歩行の類はここでは絶対に見つからない。

`geomtest.mjs` は実ブラウザでシーンを組み、`walls / buildings / ground /
monuments / steps` の**実三角形**を XZ グリッドに索引したうえで、本物の
`auto.update()` を回して測る。真実源は描画されたポリゴンだけ。

```sh
python3 -m http.server 8765 &
node tools/geomtest.mjs            # 4ルート全部
node tools/geomtest.mjs minceta    # ルートを指定
node tools/geomtest.mjs --scan     # 手で歩く場所も(街路・階段・歩廊・広場を総なめ)
```

| 検出 | 意味 |
|---|---|
| `PIERCE` | 胸の高さの移動線分が石の三角形を横断した(= 壁抜け) |
| `EMBED` | 胸の高さの八方光線の 5/8 以上が 0.3m 以内で石に当たる(= 石の中に立っている) |
| `FLOOR_LOW` | 描画の床が足より低い(浮いている) |
| `FLOOR_HIGH` | 足より上に床面がある(石にめり込んでいる・頭がつかえる) |
| `OVER_SEA` | 足の下に床が無い / 床が海面下(= 海の上を歩いている) |

一点だけ調べたいときは `tools/probe.mjs x:z[:y]` — 真上からの当たりを全部
並べ、`y` を渡すと胸の高さの周囲 2.5m もスキャンする。

```sh
node tools/probe.mjs 180.4:53.9 -112.2:-78.4:25.1
```

## 予算

ドローコール 実測 **130〜194** / 予算 200、三角 1.6〜2.5M、fps 46〜60。
うち GTAO の深度・法線プリパスがシーンをもう一度描くぶんが約半分を占める
(空・海・遠景はプリパスから外してある。**人は外さない** — 外すと
人物の画素の AO が「背後の物の AO」になり、体に背景が透けて焼き付く)。
家 700+・窓 2400・鎧戸 4200・石段 2000・メルロン 216・松 420・布 180 — すべてインスタンスかマージ。
